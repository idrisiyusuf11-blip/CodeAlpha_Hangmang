# Task 1: Enhanced Hangman Game

A classic text-based Hangman game built with Python. This version features an interactive console UI with ASCII art and color-coded feedback.

 🚀 Features
* **Visual Gallows:** Dynamic ASCII art that updates with every mistake.
* **Input Validation:** Prevents duplicate guesses and non-alphabetic characters.
* **Colorful UI:** Uses ANSI escape codes for a vibrant terminal experience.

 🛠️ Key Concepts
* Random word selection (List/Random)
* While loops & Conditional logic
* String manipulation

🕹️ How to Run
1. Navigate to the folder.
2. Run: `python hangman.py`
