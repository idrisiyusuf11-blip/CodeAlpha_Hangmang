Hangman Game – Python

Project Description
This project is a console-based Hangman game where the player guesses a hidden word one letter
at a time. The player is allowed a maximum of 6 incorrect guesses before the game ends. The
game includes ASCII-style hangman graphics displayed after every wrong attempt.

Features
• 5 Predefined Words
• Maximum 6 Wrong Attempts
• ASCII Hangman Drawing (Visual Stages)
• Input Validation (Single Letter Only)
• Tracks Guessed Letters
• Win / Lose Detection
• Clean Console Output

Technologies Used
• Python 3
• random module
• while loop
• if-else conditions
• strings and lists

How to Run the Project
• Install Python (if not already installed).
• Download or clone the repository.
• Open terminal in the project folder.
• Run: python hangman.py

Game Rules
• Guess the hidden word one letter at a time.
• Enter only one letter per attempt.
• You have 6 incorrect guesses allowed.
• If the hangman drawing completes, you lose.
• If you guess all letters before 6 wrong attempts, you win.
